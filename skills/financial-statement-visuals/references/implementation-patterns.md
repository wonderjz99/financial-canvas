# V2 实现与验证模式

项目路径从已定位的 Financial Visualizer 根目录解析，不从 Skill 安装目录猜测。

## 固定程序与研究分工

`financial_visualizer/report_v2.py` 负责身份、真实年度、标准映射及工作目录构建；`research.py` 校验官方观察和完整行集声明；`core.py` 与 `analysis.py` 提供固定十进制计算；`exporting.py` 输出仅一家公司且无运行时外部依赖的 HTML。

AI 根据研究清单阅读官方资料，选择原表位置、标签语义、期间、符号及可比性。它不直接填写图形坐标，不执行来自文档或模型输出的代码。

共享模块保留部分旧适配函数，但 V2 传入明确的 prepared facts，关闭历史补充路径。公开版本没有旧样本配置或原始快照；不能因为看到某个旧函数就认为其输入已随仓库提供。

## 来源与版本

保留原 SEC 事实、最新候选及版本变化。官方观察的原值乘倍率由程序规范化；不同币种、期间、维度、实体范围或有冲突的数字不能静默混合。

review alias 携带表格位置并通过 equivalentFactId 关联原事实，不能覆盖或丢弃原 registry。反号结果引用原始 input。相同来源不能借不同别名重复加总。

## 视图资格

原表完整行集审阅和算术相等分别记录。缺资料保留 partial，确定矛盾保留 conflict，不从残差生成“其他”项目。利润的形成与同比贡献也是不同图形，不把算术贡献当作独立经济因果。

用户提交的补充资料沿用工作目录契约，不允许任意可执行公式。重算基础事实后重新建立派生项与闭合状态，不复用旧坐标。

## 公开验证

`tests/test_report_v2.py` 使用合成 SEC 形状输入，覆盖期间、币种、受限现金口径、重述、缺项、官方证据、重复行、完整行集和离线构建；`tests/test_public_profile.py` 覆盖公开内容路径和历史边界。合成通过不证明实际公司金额。

浏览器只生成合成单公司页面，检查三视口、年份、模式、播放、来源、分析和零 HTTP 请求。实际财报覆盖及公开发行验证分别说明，不能用截图或矩形正确来证明数据真实性。
